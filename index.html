      Course overview

      Overview

      This course introduces basic concepts of visual programming. The course is of a weight of three credit hours. The course is associated with a lab in which students are given weekly programming assignments and projects with a guide from a teaching assistant. The course requires a student to have access to an installed Microsoft Visual Studio .Net IDE and C# compiler to practice the examples given in the lab. The course has several reference textbooks, and the slides are uploaded on MyGJU regularly. Email is the preferred and fundamental method of communication between students and faculty. Nonetheless, students' questions can be discussed during office hours.

      Description

      The main goal of this course is to equip students with knowledge about visual programming concepts and the skills required to design and implement different desktop applications.

      Objectives

      • The course describes the environment of visual programming languages and allows students to build high-quality visual applications using C#.
      • The course starts reviewing the basic concepts of object-oriented programming, such as encapsulation, data abstraction, and inheritance.
      • The course covers the foundations of user interface design and development with an emphasis on developing usable interfaces using controls, components, and event handling.
      • The course exposes students to how to build a desktop application that connects to a database and performs queries and database operations.
      • The course introduces students to graphics, drawing methods, and mouse and keyboard event handling.
      • The course covers exception-handling techniques, string operations, and formatting, and file operations in the context of building desktop applications.

      Textbooks

      • Paul and Harvey Deitel, "Visual C# How to Program", 6, 2016

      CS254 Visual Programming Lab · December 2025 · Alshihan, Dima

      Final Project

      In plain words
      Build one Java desktop app with a partner that uses most of the course: at least two windows, many kinds of components, several event listeners, dialogs, drawing, a table, and a database. You're graded individually on your files, how well you understand them, and your presentation. It counts for 10% of the course grade.

      Description

      The main objective of this project is to apply & practice the concepts covered throughout the course, in a practical and integrated manner.

      Students are required to develop a responsive Java application featuring an interactive Graphical User Interface (GUI). The application must be connected to a database, handle events, and display graphics and tables.

      This is a group-based activity, with 2 students per group only. Both group members must contribute equally. However, each student is individually responsible for understanding and explaining all parts of the application.

      Project Requirements

      Your project must include the following components:

      1. Creation of multiple frames.
      2. Use of various graphical components.
      3. Implementation of panels, panes, multiple event listeners.
      4. Proper handling of user input.
      5. Handling events efficiently.
      6. Use of dialog boxes.
      7. Display of graphics and tables.
      8. Database integration for data storage and retrieval.

      Project Submission Guidelines

      • Submission deadline: January 3rd, 2026, at 11: 59 pm.
      • Please submit source files only (java, .png, .jpg … etc.) Do not upload the entire project folder.
      • Submission must be completed through the designated submission section on eLearning before the deadline.
        Late submission will not be tolerated for any reason!
      • Please note that the maximum submission size is 20 MB and maximum number of files is 10.
      • Grades Release: Project grades and the total lab grade will be announced before Thursday, January 8th, 2026, which is the last day to withdraw courses.

      Evaluation Policy

      • This project is graded out of 130 points which will contribute 10% of the total course grade.
      • Although the project is completed in groups, grading is individual.
      • Group members are not guaranteed the same grade, as evaluation is based on: Submitted files, Individual understanding and Project presentation.
      • The evaluation date will be on 4 & 5 January 2026, during your lab session, time slots will be shared later.
